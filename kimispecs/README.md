# Kimi Specs Index

This directory contains detailed feature specifications for proposed MindFriend enhancements.

## Specs

- **Action Autopilot** - `01-action-autopilot-spec.md`
  - Mood-to-plan generation, calendar scheduling, and completion tracking.
- **Coping Kits** - `02-coping-kits-spec.md`
  - One-tap support bundles with micro-steps and feedback.
- **Recovery Mode UX** - `03-recovery-mode-ux-spec.md`
  - Low-friction UI mode with gentle notifications and reduced pressure.
- **Companion Memory** - `04-companion-memory-spec.md`
  - Daily intent plus user-controlled AI memory vault.
- **Quest Arcs** - `05-quest-arcs-spec.md`
  - Multi-week quest programs with milestones and arc progression.
- **Insight Lab** - `06-insight-lab-spec.md`
  - 7-day experiments with adherence tracking and outcome reports.
- **Progress Stories** - `07-progress-stories-spec.md`
  - Shareable weekly story cards derived from summaries and stats.
- **Ritual Circles** - `08-ritual-circles-spec.md`
  - Synchronized circle rituals with prompts, attendance, and recap posts.
- **Partner Mode UX** - `09-partner-mode-ux-spec.md`
  - Partner onboarding, sharing preferences, and shared activities UI.
- **Private Vault Journal** - `10-private-vault-journal-spec.md`
  - Local-only encrypted journaling with biometrics.
- **Smart Notifications Context** - `11-smart-notifications-context-spec.md`
  - AI timing optimization and contextual suggestions beyond quiet hours.
- **Dynamic Generative Content** - `12-dynamic-generative-content-spec.md`
  - AI-generated sleep stories, meditations, and exercises with personalization.
- **Community Creator Economy** - `13-community-driven-content-creator-economy-spec.md`
  - Licensed creators publish content with revenue share and curation.
- **Advanced Integrations** - `14-advanced-integrations-spec.md`
  - Calendar analysis for stress predictors and cross-platform sync.
