PROMPT 1: SLEEP & WIND-DOWN
================================================================================

Implement the Sleep & Wind-Down feature for MindFriend based on the specification in opus-specs/01-sleep-wind-down.md.

Requirements:
1. Create the database migrations for: sleep_content, user_sleep_settings, sleep_logs, sleep_sessions, and soundscape_mixes tables with full RLS policies
2. Build the Swift models: SleepContent, UserSleepSettings, SleepLog, SleepSession, SoundscapeMix
3. Create SleepService.swift with methods for: fetching sleep content by category, logging sleep sessions, managing user sleep settings, creating custom soundscape mixes
4. Implement the Edge Function "get-sleep-insights" that analyzes sleep patterns and returns personalized recommendations
5. Build the SwiftUI views: SleepHomeView (with categories for stories, soundscapes, music), SleepPlayerView (with timer, background playback), BedtimeReminderSettingsView
6. Integrate with the existing audio playback infrastructure for background audio and lock screen controls
7. Add bedtime reminder notifications using the existing notification system

Focus on Phase 1 first (sleep stories and soundscapes playback), then Phase 2 (wind-down routines and smart bedtime).
