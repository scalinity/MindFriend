Claude Code Implementation Prompts for MindFriend KimiSpecs

This file contains implementation prompts for every spec in kimispecs/.

PROMPT 1: Action Autopilot (Mood to Plan + Calendar)
/dev-pipeline
Feature: Action Autopilot (kimispecs/01-action-autopilot-spec.md)
Context: Generate 5-15 minute micro-plans after mood check-ins or summaries with optional scheduling.
Implementation: Edge Functions generate-action-plan/record-action-plan; action_plans tables + RLS; SwiftUI plan sheet, quick vs standard, edit/swap/remove, EventKit scheduling with local notification fallback; completion tracking and feedback; tests.
Constraints: 2-4 items, 5-15 min (quick 5-8), regenerate once/day, quiet hours enforced, fallback plan on failure.

PROMPT 2: Coping Kits
/dev-pipeline
Feature: Coping Kits (kimispecs/02-coping-kits-spec.md)
Context: One-tap bundles of short steps for stress, overwhelm, sleep, or low energy.
Implementation: coping_kits templates + user_coping_kits; Edge Functions get-coping-kits/track-coping-kit; home card and kit detail UI; pinning, feedback, resume support; tests.
Constraints: 2-3 steps, 3-8 minutes, fallback to generic breathing if step missing.

PROMPT 3: Recovery Mode UX
/dev-pipeline
Feature: Recovery Mode UX (kimispecs/03-recovery-mode-ux-spec.md)
Context: Low-friction mode triggered by mood trends or manual toggle with simplified home and gentler notifications.
Implementation: user_settings fields for recovery mode; Edge Function evaluate-recovery-mode; recovery banner and simplified Home layout; notification throttling; settings toggle; tests.
Constraints: Reduce notifications 50%, respect quiet hours, minimum 24h duration, never block crisis resources.

PROMPT 4: Companion Memory (Daily Intent + Editable Memory)
/dev-pipeline
Feature: Companion Memory (kimispecs/04-companion-memory-spec.md)
Context: Daily intent prompt plus user-controlled memory vault for chat personalization.
Implementation: companion_memory + daily_intents tables and RLS; Edge Functions get/update/delete; chat prompt injection with memory-used indicator; UI for intent banner and memory vault; tests.
Constraints: Intent max 140 chars, expires after 24h, memory optional with cap 20, proceed without memory if fetch fails.

PROMPT 5: Quest Arcs and Programs
/dev-pipeline
Feature: Quest Arcs (kimispecs/05-quest-arcs-spec.md)
Context: Multi-week quest programs with milestones and arc-based quest selection.
Implementation: quest_arcs tables; Edge Functions get/start/pause; update quest assignment for arc steps; milestone rewards; UI for arc catalog/detail/home card; tests.
Constraints: One active arc; arc day advances on completion; fallback to normal quests if arc step missing.

PROMPT 6: Insight Lab Experiments
/dev-pipeline
Feature: Insight Lab (kimispecs/06-insight-lab-spec.md)
Context: 7-day experiments with adherence tracking and outcome reports.
Implementation: insight_experiments tables; Edge Functions start/record/generate report; experiment catalog, daily check-in, report UI; reminder scheduling; tests.
Constraints: One active experiment; 7-day duration; reduced report if baseline missing; allow early exit after missed days.

PROMPT 7: Progress Stories (Shareable Weekly Recap)
/dev-pipeline
Feature: Progress Stories (kimispecs/07-progress-stories-spec.md)
Context: Weekly recap converted into swipeable story cards that can be saved or shared.
Implementation: weekly_stories table; Edge Function generate-weekly-story; story viewer with share/save; circle share flow; card rendering and export tests.

PROMPT 8: Ritual Circles
/dev-pipeline
Feature: Ritual Circles (kimispecs/08-ritual-circles-spec.md)
Context: Synchronized 3-5 minute rituals with shared prompts and recap posts.
Implementation: circle_rituals tables; Edge Functions create/join/complete; realtime updates or polling; ritual UI with shared timer and recap post; tests.

PROMPT 9: Partner Mode UX
/dev-pipeline

Context: Partner linking, sharing preferences, and shared activities using existing buddy data.

PROMPT 10: Private Vault Journal
/dev-pipeline
Feature: Private Vault Journal (kimispecs/10-private-vault-journal-spec.md)
Context: Local-only encrypted journal protected by biometrics and excluded from AI.
Implementation: CryptoKit AES.GCM encryption, Keychain-managed keys, LocalAuthentication gating, vault UI and local search, tests.
Constraints: No cloud sync; passcode fallback; missing key prompts reset with data loss warning.

PROMPT 11: Smart Notifications With Context
/dev-pipeline
Feature: Smart Notifications With Context (kimispecs/11-smart-notifications-context-spec.md)
Context: Context-aware notifications with on-device prediction and adaptive learning.
Implementation: on-device ML model, context engine, notification queue/bundling/suppression, settings UI for frequency/types/quiet hours, engagement logging, tests.
Constraints: Notify only if predicted engagement >60%, on-device context processing, quiet hours respected, urgent crisis notifications bypass bundling.

PROMPT 12: Dynamic Content + Generative Audio
/dev-pipeline

Context: AI-generated wellness content with voice synthesis and safety guardrails.
Implementation: Edge Function generate-content, TTS integrations, audio assembly/mixing, content validation and clinical review workflow, SwiftUI request/playback UI, caching/rate limits, tests.

PROMPT 13: Community-Driven Content + Creator Economy

PROMPT 14: Advanced Integrations
/dev-pipeline

Context: Calendar, email, smart home, travel, wearables, API, and FHIR integrations.
